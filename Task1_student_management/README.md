# Task 1 - Flask API + Streamlit
```
pip install -r requirements.txt
python app.py                    # terminal 1 -> http://127.0.0.1:5000
streamlit run streamlit_app.py   # terminal 2
```
SQLite file `students.db` and the `students` table (id, name, department, email) are created automatically.

Endpoints: GET /students, GET /students/<id>, POST /students, PUT /students/<id>, DELETE /students/<id>
